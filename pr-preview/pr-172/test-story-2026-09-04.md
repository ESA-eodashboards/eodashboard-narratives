#### Kernel NDVI Overview
The Kernel Normalized Difference Vegetation Index (kNDVI) provides a non-linear generalization of the standard NDVI. By leveraging machine learning kernels, this dataset helps in monitoring vegetation health and phenology with higher sensitivity to dense vegetation, effectively mitigating saturation effects commonly found in standard indices. This layer is sourced from the Earth System Data Lab (ESDL), offering a consistent global view of ecosystem productivity.
